Library

A central list of channels and contacts, shared by everyone using this server. Add them to any radio from the Zone and Contacts editors.

Name, tags and notes can be edited in place. Channel settings are edited in a radio's Zone editor and saved back with Functions → Save Channels to Library.

Import from CPS2 XML

Paste Zone XML (every channel in every zone is imported) or Contacts XML.

Import from RadioReference

On a RadioReference page, select the frequency table (including the header row), copy it and paste it here. DMR rows become digital channels and FM/FMN rows become analog channels.
