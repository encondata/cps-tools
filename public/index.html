CPS2 Tools

Bulk-edit MOTOTRBO codeplug data that CPS2 can't import or export. Copy an item in CPS2, paste its XML into an editor, change it like a spreadsheet, then copy the new XML and paste it back into CPS2.

How it works

  1. Paste — in CPS2, copy the Zones, Scan Lists, RX Group Lists and Contacts, and paste the XML on the Setup page (or into an editor). It's kept in this browser's workspace.
  2. Edit — change values in the grid, paste blocks from Excel, add, duplicate, reorder or delete rows.
  3. Copy — copy the generated XML and paste it back into CPS2. The Setup page shows which parts changed.

Everything runs in your browser. Nothing you paste is sent to the server.
